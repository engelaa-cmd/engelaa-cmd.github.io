Privacy Policy

Effective date: November 18, 2026

Gunggeumhanyang (궁금하냥) is a desktop application used by the channel owner for their own YouTube account. It uses YouTube API Services to access the owner's account for uploading videos and viewing the owner's channel and videos. It can also delete the owner's test videos. It does not collect other people's data.

OAuth tokens are stored only on the owner's PC. The application logs only the uploaded video ID as the upload result. Tokens are not sent to other people, and the application does not share any data with third parties.

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

You can revoke the application's access at any time through Google security permissions.

Data deletion: after access is revoked, the stored token no longer works. The owner deletes the token file and the upload log (video IDs) from the PC at any time, and in any case within 30 days of revoking access. To delete such data, contact the address below. Videos already uploaded to YouTube are not deleted by this application; they can be deleted separately in YouTube Studio.

Contact: Ryu Seonjeong (류선정) · engelaa@gmail.com
